# What registrants see

This page describes the signup process from the registrant's point of view,
so you can explain it to them.

## Signing up

1. Open the signup sheet and select one (or, if allowed, several) timeslots.
   Full slots without a waiting list can't be selected.
2. Fill in the personal data (pre-filled for logged-in users) and, if
   configured, the {doc}`additional form <additional-form>`, and consent to
   the {doc}`data usage declaration <data-privacy>`.
3. Visitors who are not logged in may have to enter a one-time code sent to
   their email address. The code is valid for 15 minutes.
4. A summary shows the result for each selected slot (signed up, waiting
   list or waiting for confirmation), and an {doc}`email <emails>` is sent.

## My signups

Logged-in users can see and cancel their upcoming signups of a signup sheet
via the _My signups_ link on the signup sheet (`@@view-my-signups`).

## Signing off without an account

The confirmation, wait for confirmation and waiting list emails can contain a
personal link to sign off directly, without logging in (placeholder
`$$sign_off_url$$`, included in the default texts). This is how registrants
without an account cancel their signup.
