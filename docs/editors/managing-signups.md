# Managing signups

## Timeslot view

The page of a timeslot lists all its persons, grouped by state: signed up,
waiting list, waiting for confirmation and signed off.

## Manager summary

The manager summary (`@@manager-summary` on the signup sheet) shows all
days, timeslots and persons of a signup sheet at a glance, with the state
of each person.

### Export to CSV

Export the signups as a CSV file, for example to open it in Excel. Choose

- whether to include empty slots,
- which states to include (waiting for confirmation, signed up, signed off,
  waiting list) and
- the separator (comma, semicolon or tab).

The file contains date, time, name, email address and state of each signup.

### Remove all persons

Deletes all persons of the signup sheet, regardless of their state - for
example to remove test signups, or before reusing a signup sheet.

:::{warning}
This can't be undone, and the persons are **not** notified.
:::
