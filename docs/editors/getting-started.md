# Getting started

Setting up a new signup sheet takes three steps:

1. **Create a signup sheet.** In the folder where the signup sheet should be
   located, choose _Add new… > UTSignupSheet_. Enter a title, an
   introduction text and the contact email address, and review the other
   {doc}`settings <signup-sheet-settings>`.
2. **Add days.** Inside the signup sheet, choose _Add new… > UTDay_ and pick
   a date. Repeat for each date.
3. **Add timeslots.** Inside each day, add timeslots with
   _Add new… > UTTimeslot_, or create a whole series of equally sized
   timeslots at once (see {doc}`timeslots`).

Optionally, create an `EasyForm` inside the signup sheet and select it as
{doc}`additional form <additional-form>` to ask registrants for further
information.

Finally, publish the signup sheet (and the EasyForm, if you use one - otherwise
visitors can't open the signup sheet). Visitors can now open it, choose one (or
more) timeslots and sign up.

:::{tip}
Keep the signup sheet private while setting it up, and test the signup
yourself. You can remove all test signups afterwards in the
{doc}`manager summary <managing-signups>`.
:::
